# AI Engineering — 7 weeks, from zero to paid and deployed

For people who have never coded and want to build AI applications, not just call APIs.

| Week | Topic | What you can do at the end |
|------|-------|----------------------------|
| 1 | Foundations & Prompt Engineering | Read and write basic Python; build a prompt template that produces consistent output |
| 2 | System Design & Pydantic | Describe data with models so bad input fails loudly instead of silently |
| 3 | FastAPI, Docker, PostgreSQL | Put a working endpoint behind a URL that survives a container restart |
| 4 | Complete RAG Pipelines | Make an LLM answer from *your* documents instead of its memory |
| 5 | Monitoring & Evaluations | Prove the answer got better, not just different |
| 6 | Production Deployment | Ship it, roll it back, and know when it breaks |
| 7 | Keys, Credits & M-Pesa | Charge for the thing through a Daraja STK Push |

Everything above builds the service described in [../../product/README.md](../../product/README.md).

## Week 1

Start at [week1_foundations/PLAN.md](week1_foundations/PLAN.md).

```
python week1_foundations/lessons/01_variables_and_types.py
```

## How to study this
- One lesson per day. Under 30 minutes.
- Type the code. Do not paste.
- When you get an error, read the last line first, then the file and line number above it.
- Answer the day's question out loud before moving on. If you cannot, reread the lesson.
